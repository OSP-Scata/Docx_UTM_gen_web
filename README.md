# Веб-сервис автоматической UTM-разметки файлов Word (.docx)

Простой и легкий веб-инструмент для контент-маркетологов и SMM-специалистов. Позволяет массово добавлять UTM-метки в гиперссылки внутри готовых статей формата Word без ручного копирования.

## 🚀 Живой демо-стенд
Сервис развернут в Docker-контейнере на личном VDS, защищённом Trycloudflare:
👉 **[Попробовать генератор тут](https://producer-privilege-dom-ours.trycloudflare.com/)**

## 🛠️ Что умеет сервис

1. **Разметка одной статьи:** Пользователь вводит кампанию, отмечает галочками нужные соцсети (или вводит свои через запятую), загружает `.docx` и получает ZIP-архив с готовыми копиями файлов под каждую платформу.
2. **Массовая обработка (Batch):** Пользователь загружает ZIP-архив со статьями и заполненную Excel-таблицу (манифест) с инструкциями. Сервис автоматически сопоставляет файлы, размечает ссылки и отдает итоговый архив.
3. **Защита от ошибок ввода:** Встроенная функция автоматически переводит русские названия кампаний и площадок в латиницу, приводит к нижнему регистру и заменяет пробелы на подчеркивания для корректной работы систем аналитики.

## 🧠 Стек технологий

- **Бэкенд:** Python 3.11+, FastAPI, uvicorn, python-docx (работа с XML-структурой Word), openpyxl (чтение таблиц Excel).
- **Фронтенд:** Семантический HTML5, CSS3 (адаптивная верстка на Flexbox), асинхронный JavaScript (Fetch API, динамическое переключение вкладок без перезагрузки).
- **Инфраструктура:** Docker (сборка slim-образа), Nginx (обратный прокси), SSL от Let's Encrypt.

## ⚙️ Особенности реализации (Безопасность и оптимизация)

- Ограничение размера файлов до 10 МБ на бэкенде для защиты сервера от перегрузки.
- Проверка размера разархивируемых файлов при массовой загрузке через ZIP-архив (защита от ZIP-бомб).
- Проверка расширения + 2 байтов заголовка документов Word для защиты от загрузки некорректных файлов.
- Игнорирование оригинальных имен файлов при сохранении на диск (защита от уязвимости Path Traversal).
- Ограничение длины вводимых строк 100 символами, ограничение допустимых символов русскими/английскими буквами, дефисом, подчеркиванием и пробелом.
- Защита парсера `lxml` для предотвращения XML-инъекций через структуру `.docx`.
- Автоматическая очистка временных файлов на диске: папка полностью зачищается с помощью менеджера жизненного цикла `lifespan` при старте/остановке сервера, а готовые ZIP-архивы удаляются сразу после скачивания через фоновые задачи `BackgroundTasks`.
- Все процессы и ошибки фонового удаления записываются в лог-файл `server.log`.

```text
├── static/

├── templates/
│   └── index.html              # HTML-шаблон главной страницы (Jinja2)
├── app.py                      # Бэкенд-логика, транслитерация, эндпоинты
├── Dockerfile                  # Инструкция для сборки контейнера
└── requirements.txt            # Список зависимостей
```

## 💻 Локальный запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com
   cd название_репозитория
   ```
2. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустить сервер:
   ```bash
   uvicorn app:app --reload
   ```
4. Открыть в браузере: `http://127.0.0.1:8000`

## 🐳 Запуск в Docker

```bash
docker build -t utm-service .
docker run -d -p 8080:8000 --name my-utm-site --restart always utm-service
```
